About this Screen

This is the graph options menu in CNC12.

Tool Marker Color Fill Opacity:

The percentage of how "see through" the tool indicator is

Tool Marker Height:

The height of the tool indicator in units

Tool Marker Width:

The width of the tool indicator in units

Soft Travel Limit Color Fill Opacity:

The percentage of how "see through" the work envelope box is
Set to 0 to NOT add Color Fill to the Soft Travel Limits, change color with the color picker in the utility menu

G-code Smoothing Actual Tool Path:

Displays effects of smoothing in the graph

Display Encoder Indicated Spindle RPM:

Allows a real-time display of the current spindle speed in RPM

Display Coordinate System Rotation:

Displays CSR Positions in graphing

Display A and B axis Rotation:

Displays A and B rotations for machines with a Rotary Axis

Display XY Skew Correction:

Displays Skew Correction

Display Lash Compensation Moves:

Displays Lash/Screw Compensation

Display Extended Tools:

Displays the 'extended' tools on the graph by default

3D Run Time G code Graphics:

Use 3-Dimensional Run Time Graphics

API Information

The CentroidAPI can be used to get information fom the main screen in CNC12, such as the DRO labels and position, the currently active WCS, and more.
