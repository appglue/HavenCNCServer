Keyboard Shortcuts

  • Ctrl E = PLC Detective
  • Alt D = Toggle DRO between Machine CS and Work CS
  • Ctrl D = Toggle DRO between Current Position and Distance To Go
  • Alt J = Keyboard Jogging
  • Alt K = Display ATC Bin
  • Ctrl C = Copy
  • Ctrl X = Cut
  • Ctrl V = Paste
  • Alt P = Display PID Values
  • Ctrl Q = Launch Probe Cycles History
  • Alt T = Display Temperature
  • Alt V = Display Version
  • Alt 1 = Change to WCS 1
  • Alt 2 = Change to WCS 2 (License Required)
  • Alt 3 = Change to WCS 3 (License Required)
  • Alt 4 = Change to WCS 4 (License Required)
  • Alt 5 = Change to WCS 5 (License Required)
  • Alt 6 = Change to WCS 6 (License Required)
  • Alt 7 = Change to WCS 7 (License Required)
  • Alt 8 = Change to WCS 8 (License Required)
  • Alt 9 = Change to WCS 9 (License Required)
  • Alt 0 = Change to WCS 10 (License Required)
  • Alt - = Change to previous WCS (License Required)
  • Alt + = Change to next WCS (License Required)
  • Space Bar = Toggle Choices
  • Arrow Keys = Move Selection
  • Shift F9 = Set XY
  • Shift F10 = Set All
