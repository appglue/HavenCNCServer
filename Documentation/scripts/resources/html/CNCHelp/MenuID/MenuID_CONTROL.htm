About this Screen

This is the control configuration menu.

DRO Display Units

Units of the Digital Read Out. Either Inches or Millimeters.

Machine Units

Units of the machine. Either Inches or Millimeters.

Max Spindle

The maximum spindle rpm at 10 volt analog output.

Min Spindle

The minimum spindle rpm that the spindle overcomes friction.

Machine Home At Powerup

Operator Jog

Homes machine at current location

Home Switch

Homes machine to home switches Runs home program.

Reference Mark-Home Switch

Homes machine to reference mark (index pulse) or home switches. Runs home program.

Home In Place

Homes machine on startup at current or last known location.

Absolute

Homes machine at absolute encoder location. Runs home program.

Operator Control Panel

M400-M39

Uses physical jog panel.

M400-M39 with VCP

Uses both physical jog panel and the virtual control panel.

Virtual Control Panel Only

Uses the virtual control panel.

Offline

Uses neither the physical jog panel nor the virtual control panel. Not recommended.

Check For Operator Panel

Puts the system in a fault state if the physical jog panel is disconnected.

Require Two Cycle Start Presses To Begin Job

Requires two (2) presses of the Cycle Start button to start a job.

Remote Drive & Directory

This field sets up the remapped default drive and directory for the F3 – Remote key in the Load Job screen. This allows you to conveniently load files from an attached computer via LAN (an RJ-45 Ethernet connection). The Control will usually remap the attached computer’s C: hard drive as drive E:, depending on the way it was set up.

API Information

The CentroidAPI can be used to get information fom the main screen in CNC12, such as the DRO labels and position, the currently active WCS, and more.
