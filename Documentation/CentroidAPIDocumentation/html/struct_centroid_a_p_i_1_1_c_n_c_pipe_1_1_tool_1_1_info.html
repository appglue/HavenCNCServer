CentroidAPI.CNCPipe.Tool.Info Struct Reference

Documentation

Structure to hold tool library info.

Public Attributes

int number
 Tool Number.
 
int bin
 This field tells the bin number of tool.
 
int h_number
 This field specifies a default Height Offset (H) number to use with each tool. Possible values are 1 to 200. Intercon uses this information to provide a default H value at each tool change.The CNC software also uses this information to correct for the length of the tool that is used to establish the Z-axis position in Part Setup.
 
double height_offset
 This is the distance the control adjusts Z-axis positions when tool length compensation (G43 or G44) is used with a particular H value.
 
int d_number
 This field specifies a default Diameter (D) number to use with each tool. Possible values are 1 to 200. Intercon uses this information to provide a default D value at each tool change.
 
double diameter_offset
 This field tells the control the distance to adjust when cutter diameter compensation (G41 or G42) is used with a particular D value.
 
Coolant coolant
 This field specifies a default coolant type to use with each tool. Possible values are FLOOD, MIST, or OFF. Intercon uses this information to automatically insert M7 or M8 after a tool change.
 
SpindleDirection spindle_direction
 This field specifies a default spindle direction to use with each tool. Possible values are CW, CCW, or OFF. Intercon uses this information to automatically insert M3 or M4 after a tool change.
 
int spindle_speed
 This field specifies a default spindle speed to use with each tool. Possible values are 0 to 500000. Intercon uses this information to automatically insert an S code after a tool change.
 
string description
 Tool Description. Max size of 20 characters.
