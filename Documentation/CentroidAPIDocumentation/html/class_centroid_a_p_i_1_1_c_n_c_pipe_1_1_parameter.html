◆ GetMachineParameterValue()

ReturnCode CentroidAPI.CNCPipe.Parameter.GetMachineParameterValue ( int parameter_num,
out double parameter_value )

Get the value of a machine parameter or user variable.

Parameters
parameter_numThe number of the machine parameter to get (0-999) or user variable (29000 - 34999)
parameter_valueThe value of said machine parameter or user variable
Returns
SUCCESS or an error code.
// Get the value for machine parameter 32 and store it as myParamValue.
returnCode = cnc_pipe.parameter.GetMachineParameterValue(32, out double myParamValue);

Note: the reading of user variables 29000-34999 can occur in any job run state or in any menu.

Since
v5.24
